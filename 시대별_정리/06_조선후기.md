# 조선 후기 (임진왜란 이후 ~ 흥선대원군 집권 전, 왕위 순서대로)

> 조선 전기/후기는 임진왜란(1592)을 기준으로 구분

| 왕 | 업적 |
|---|---|
| 광해군 | 기유약조 체결, 중립외교(명·후금 사이), 대동법 최초 실시(경기도, 이원익 건의), 『동의보감』 편찬, 영창대군 사사·인목대비 유폐 → 인조반정으로 폐위 |
| 인조 | 인조반정으로 즉위, 이괄의 난(공산성 피신), 영정법 실시, 정묘호란(강화도 피난, 정봉수·이립의 용골산성 전투) → 병자호란(척화주전론 김상헌 vs 주화론 최명길, 김준룡 광교산 전투, 남한산성 항전 → 삼전도 항복, 소현세자·봉림대군 청에 볼모) |
| 효종 | 북벌 추진(어영청 중심, 송시열), 나선정벌(조총부대 파견), 광산 채굴 허용 |
| 현종 | 예송논쟁 2차례(서인·남인 간 상복 문제) |
| ★숙종 | 상평통보 전국 유통, 백두산정계비 건립(청과 국경 확정), 환국 정치(경신환국→기사환국→갑술환국, 송시열 사사·인현왕후 폐위 등), 금위영 설치로 5군영 완성 |
| ★영조 | 탕평비 건립·탕평책, 이인좌의 난(정희량 등 반란) 진압, 균역법 실시(군역 2필→1필), 『속대전』·『동국문헌비고』 편찬 |
| ★정조 | 초계문신제, 장용영 설치, 규장각 설치(검서관 등용), 신해통공(금난전권 폐지), 수원화성 축조, 신해박해(윤지충 처형), 『대전통편』·『동문휘고』 편찬 |
| 순조 | 신유박해(황사영 백서 사건), 공노비 해방, 세도정치 시작(안동 김씨 등), 매관매직 성행, 홍경래의 난(평안도 차별에 반발) |
| (세도정치기: 순조-헌종-철종) | 임술농민봉기(진주, 유계춘 주도, 철종 때) → 삼정이정청 설치(박규수 건의) |

## 조선 후기 경제

- **수취제도 변화**: (세종) 연분9등법 → (세조) 직전법 → (인조) 영정법
- **대동법**(광해군, 방납의 폐단 해결): 토산물 대신 쌀·돈·무명으로 납부(토지 1결당 12두), 공인 등장
- **균역법**(영조, 군역 부담 완화): 군포 2필→1필, 결작(토지 1결당 쌀 2두)·선무군관포로 보충
- 상품화폐경제 발달: 도고·덕대·보부상, 설점수세제, 송상(개성 상인) 활동, 은화의 무분별한 사용
- 구황작물(감자·고구마) / 상품작물(고추·담배·인삼 등) 재배 확대

## 조선 후기 사회·문화

- 서얼: 통청운동(청요직 진출 요구) / 중인: 시사(詩社) 조직
- 납속·공명첩을 통한 신분 상승 → 신분질서 동요
- 한글소설(홍길동전·춘향전)·사설시조·판소리·탈춤·신대놀이 유행

## 조선 후기 유학·사상 (참고)
- 서원 최초: 주세붕(풍기군수)이 세운 백운동 서원 → 소수서원으로 사액
- 이황: 『성학십도』, 기대승과 사단칠정 논쟁, 예안향약
- 이이: 『성학집요』·『동호문답』, 해주향약
- 양명학: 정제두(강화학파)
- 박세당: 『색경』, 주자와 달리 해석하여 사문난적으로 몰림(『사변록』)
