# 고려시대 (왕위 순서대로)

## 고려 초기

| 왕 | 업적 |
|---|---|
| ★태조 왕건 | 훈요 10조·「정계」·「계백료서」, 역분전 지급, 흑창 설치, 서경 중시, 사심관제도·기인제도, 만부교 사건(거란 배척), 발해 유민 포용 |
| 광종 | 노비안검법, 과거제 실시(쌍기의 건의), 공복 제정, 연호 광덕·준풍(자주 연호) |
| 경종 | 전시과 시행(전국 대상, 시정전시과) |
| ★성종 | 최승로의 시무 28조 수용 → 전국에 12목 설치·지방관 파견, 국자감 설치, 건원중보 발행, 흑창 → 의창, 향리제 정비, 팔관회 축소 |
| 현종 | 거란의 3차례 침입(1차 서희 강동 6주, 2차 강조의 난·양규, 3차 강감찬 귀주대첩), 초조대장경 조판, 광군 조직 |

## 문벌귀족 사회

| 왕 | 업적 |
|---|---|
| 숙종 | 해동통보·은병 발행, 별무반 창설(여진 대비) |
| 예종 | 윤관의 별무반(신기군·신보군·항마군)으로 여진 정벌 → 동북 9성 설치(이후 여진에 반환), 관학 진흥(양현고·전문 7재) |
| 인종 | 이자겸의 난, 묘청의 서경 천도 운동(칭제건원·금국정벌 주장, 국호 대위·연호 천개) → 김부식 등 개경파가 진압 |
| (사회) | 최충의 9재 학당(문헌공도), 사학 12도 융성 |

## 무신집권기

- 무신정변(의종 때): 정중부·이의방 → 경대승 → 이의민 → 최충헌 → 최우(무신 집권 순서)
- 반무신 봉기: 김보당의 난, 조위총의 난
- 최충헌: 봉사 10조 제시, 교정도감 설치 / 최우: 정방 설치, 강화도 천도, 삼별초(군사 기반)
- 대몽항쟁: 박서(귀주성), 김윤후(처인성·충주성), 배중손(삼별초 – 강화도·진도·제주도로 이동하며 항쟁)
- 팔만대장경 조판(강화도)
- 하층민 봉기: 김사미·효심의 난(농민), 만적의 난(천민, 최충헌 집권기), 망이·망소이의 난(공주 명학소, 특수행정구역)

## 원 간섭기

| 왕 | 업적 |
|---|---|
| 충렬왕 | 원의 요청으로 일본 원정 참여, 관제 격하(중서문하성+상서성=첨의부), 정동행성 설치 |
| (전반) | 권문세족(친원파) 성장, 공녀·응방(매) 징발, 몽골풍 유행, 왕 호칭에 '충O왕' |
| 충목왕 | 정치도감 설치(개혁 시도) |
| ★공민왕 | 친원파 숙청(기철), 정동행성이문소 폐지, 쌍성총관부 탈환, 전민변정도감 설치(신돈 등용, 노비 해방), 관제 복구(중서문하성·상서성), 신진사대부 성장(성리학 수용, 이제현이 만권당에서 원 유학자와 교류) |

## 고려 말

| 왕 | 업적 |
|---|---|
| 우왕 | 홍건적·왜구 침입(최영-홍산대첩, 최무선-진포대첩·화포 제작, 이성계-황산대첩, 박위-쓰시마 토벌), 요동 정벌 추진(최영) → 위화도 회군(이성계) |

## 경제·사회·문화 (시대 공통)

- **경제**: 소를 이용한 깊이갈이 일반화, 공무역 중심(관영상점, 벽란도), 화폐: 건원중보(성종)·은병&해동통보(숙종), 전시과 제도
- **사회**: 특수행정구역(향·부곡·소), 제위보·구제도감·혜민국·동서대비원(사회 시책), 향교(지방 관리·서민 자제 교육)
- **불교**: 의천(천태종 개창, 교관겸수) / 지눌(조계종 개창, 수선사 결사·정혜쌍수·돈오점수, 송광사) / 혜심(유불일치설, 지눌 제자)
- **탑/불상**: 월정사 팔각구층석탑, 개성 경천사지 10층석탑(원의 영향, 대리석, 국립중앙박물관 소장 → 이후 조선 원각사지 10층석탑에 영향), 광주 춘궁리 철불, 논산 관촉사 석조미륵보살입상, 부석사 소조아미타여래좌상
- **금속활자**: 『직지심체요절』(청주 흥덕사, 현존 최고(最古) 금속활자본, 현재 프랑스 소장)
- **역사서**: 『삼국사기』(김부식, 기전체·유교사관), 『동명왕편』(이규보, 고구려 계승의식), 『해동고승전』(각훈), 『삼국유사』(일연, 불교·민간설화·고조선 계승), 『제왕운기』(이승휴, 고조선 건국이야기), 『사략』(이제현, 정통의식·대의명분)
